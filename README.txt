African Foods Company Ltd — IT SOP Portal
Files:
- index.html: static website home page and SOP sections
- style.css: responsive visual styling

To preview:
1. Keep index.html and style.css in the same folder.
2. Open index.html in a web browser, or open the folder in Visual Studio Code and use a local preview extension.
3. Before publishing, replace generic service desk contact instructions with AFC's approved contact details and obtain IT Manager/management approval.
4. Host only in an AFC-approved internal location unless management has approved public access.
